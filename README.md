# 夢想號列車

一款可以直接在瀏覽器裡玩的 3D 解謎小旅行。小艾在遊戲室等媽媽來接時，跟著兔子棉棉鑽進玩具城堡，搭上夢想號列車，一站一站去找媽媽。

**▶ 開始玩：** https://p203052000.github.io/dream-train/

手機、平板、電腦都能玩，不需要安裝。

| 第二章 | 餅乾海岸（含海底隧道） | 找出對的餅乾 |
| 第三章 | 晚霞雲端 | 把雲朵排成彩虹 |
| 第四章 | 銀河星軌 | 把星星連成愛心 |
| 奇想一～六 | 亮晶晶鏡子星雲、螢火蟲晚安星、齒輪轉轉星、積木飄飄島、彩色毛線峽谷、紙摺動物星 | 找媽媽、數螢火蟲、轉齒輪、認顏色、選顏色、認動物 |

首頁可以直接從任何一章開始。

### 兩種模式

首頁可以選「誰來玩」：

- **寶寶模式**（2–4 歲）：奇想世界的謎題點一下就過關，沒有時間限制，閒置一下會出現提示箭頭。
- **大朋友模式**（5 歲～大人）：同一個故事，換成要動腦的謎題（鏡子調包、記憶跟唱、抓時機、照大小疊積木、找規律、謎語），還有大人會心一笑的小台詞。

每個奇想世界解完謎題後，都能下車到小島上自由探索，找五個小驚喜，想走的時候再按「上車，出發」。

## 操作

- **手機**：單指拖曳轉動視角、雙指縮放；左下搖桿或點地面讓小艾走路。
- **電腦**：滑鼠拖曳轉動視角、滾輪縮放；WASD／方向鍵走路，按住 Shift 跑步；Esc 暫停。
- 每一站都能自由走路、爬山、游泳；沿著鐵軌也能一路走到下一站。
- 奇想世界的探索小島：點地面走過去，點小驚喜會自己走過去觸發。

## 技術

單一 HTML 檔，使用 [three.js](https://threejs.org/)（MIT License，由 jsDelivr CDN 載入）繪製 3D 畫面，其餘程式、圖片、音樂與音效都內嵌在 `index.html` 裡。火車、道具與各場景的精緻模型用 Blender 製作，以 glTF（.glb）格式內嵌。
