# 夢想號列車

一款可以直接在瀏覽器裡玩的 3D 解謎小旅行。小艾在遊戲室等媽媽來接時，跟著兔子棉棉鑽進玩具城堡，搭上夢想號列車，一站一站去找媽媽。

**▶ 開始玩：** https://p203052000.github.io/dream-train/

手機、平板、電腦都能玩，不需要安裝。

## 章節

| 章節 | 場景 | 謎題 |
|---|---|---|
| 序章 | 遊戲室的城堡 | 跟著兔子 |
| 第一章 | 糖果樂園 | 記住媽媽的歌 |
| 第二章 | 餅乾海岸（含海底隧道） | 找出對的餅乾 |
| 第三章 | 晚霞雲端 | 把雲朵排成彩虹 |
| 第四章 | 銀河星軌 | 把星星連成愛心 |
| 第五章 | 月亮車站 | 用鈴鐺敲出媽媽的歌 |
| 尾聲 | 沙發上醒來 | — |

首頁可以直接從任何一章開始。

## 操作

- **手機**：單指拖曳轉動視角、雙指縮放；左下搖桿或點地面讓小艾走路。
- **電腦**：滑鼠拖曳轉動視角、滾輪縮放；WASD／方向鍵走路，按住 Shift 跑步；Esc 暫停。
- 每一站都能自由走路、爬山、游泳；沿著鐵軌也能一路走到下一站。

## 技術

單一 HTML 檔，使用 [three.js](https://threejs.org/)（MIT License，由 jsDelivr CDN 載入）繪製 3D 畫面，其餘程式、圖片與音效都內嵌在 `index.html` 裡。
